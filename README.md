# MGI Education Platform (Full-Stack TypeScript & MongoDB)

A high-converting web platform and CRM created for **MGI Education** (Mayur Vihar, Delhi).

## Quick Start

### 1. Run in Development Mode
```bash
npm run dev
```
- Client runs on: `http://localhost:5173`
- API runs on: `http://localhost:5000`

### 2. Run in Production Mode
```bash
npm run build
npm start
```
- Access everything at: `http://localhost:5000`

### 3. Re-seed Database
```bash
npm run seed
```

## Admin Portal
- URL: `/admin/login` or `/admin`
- Username: `admin`
- Password: `Admin@MGI2026!`

## Features
- **University Degrees Hub**: BCA, BBA, B.Com, BA, MBA, MCA, LLB
- **NIOS Admissions Hub**: 10th & 12th open schooling guidance
- **Computer Institute Hub**: ADCA, Tally Prime + GST, Graphic & Web Designing, Advanced Excel
- **Student Verification Portal**: `/verify-certificate` (test with `MGI-2025-ADCA01`)
- **Admissions Lead CRM**: Inquiries tracking, counselor notes, CSV export, direct WhatsApp messaging
- **Notices Ticker & CMS**: Real-time urgent alerts and notices
